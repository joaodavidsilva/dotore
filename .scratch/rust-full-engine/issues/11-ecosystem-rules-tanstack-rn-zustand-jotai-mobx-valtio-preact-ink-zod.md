# 11: Ecosystem Rule Families — TanStack Query/Start, React Native/Expo, Zustand, Jotai, MobX, Valtio, Preact, Ink, and Zod

**What to build:** Port all **Capability Gate**-activated ecosystem rule families for TanStack Query, TanStack Start, React Native, Expo, Zustand, Jotai, MobX, Valtio, Preact, Ink, and Zod into the single-pass Rust engine.

**Blocked by:** 01: Prefactor Rule Registry, Capability Gate, Config Loader, and Single-Pass OXC Pipeline, 04: Module Graph, Dead Code, Circular Dependencies, and Duplicate JSX Subtrees

**Status:** ready-for-agent

- [ ] All `tanstack-query` and `tanstack-start` rules (`query-no-query-in-effect`, `query-no-mutation-in-effect-as-read`, `query-no-use-query-for-mutation`, `query-stable-query-client`, `query-no-void-query-fn`, `query-no-rest-destructuring`, `query-destructure-result`, `tanstack-start-server-fn-validate-input`, `tanstack-start-server-fn-method-order`, `tanstack-start-route-property-order`, `tanstack-start-redirect-in-try-catch`, `tanstack-start-no-use-server-in-handler`, `tanstack-start-get-mutation`, and remaining TanStack rules) are implemented in Rust.
- [ ] All 42 `react-native` and `expo` rules (`rn-no-raw-text` honoring configured `textComponents` and `rawTextWrapperComponents` across files, `rn-list-recyclable-without-types`, `rn-list-missing-estimated-item-size`, `rn-scrollview-flex-in-content-container`, `rn-scrollview-dynamic-padding`, `rn-prefer-expo-image`, `rn-style-prefer-box-shadow`, `expo-no-non-inlined-env`, and project-level React Native/Expo configuration checks) are implemented in Rust.
- [ ] All state-store rules for `zustand` (`zustand-no-mutating-state`, `zustand-no-fresh-selector-result`, `zustand-no-whole-store-destructure`, `zustand-no-get-during-initialization`), `jotai` (`jotai-select-atom-in-render-body`, `jotai-derived-atom-returns-fresh-object`, `jotai-tq-use-raw-query-atom`), `mobx` (`mobx-reaction-disposer-discarded`, `mobx-no-observer-wrapped-memo`, `mobx-no-make-auto-observable-in-inheritance`), and `valtio` (`valtio-no-proxy-read-in-render`, `valtio-no-snapshot-in-callback`) are implemented in Rust.
- [ ] All rules for `preact` (`preact-prefer-oninput`, `preact-prefer-ondblclick`, `preact-no-render-arguments`, `preact-no-react-hooks-import`, `preact-no-children-length`), `ink` (all 22 terminal UI rules including cross-file `ink-no-raw-text`), and `zod` (`zod-v4-prefer-top-level-string-formats`, `zod-v4-no-deprecated-schema-apis`, `zod-v4-no-deprecated-error-customization`, `zod-v4-no-deprecated-error-apis`) are implemented in Rust.
- [ ] Integration tests verify **Capability Gate** activation and pass all ported valid and invalid regression fixtures for each library family.
